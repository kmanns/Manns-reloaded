## Capabilities and Constraints

- Astro 5 static site using the Fuwari theme; deployed to GitHub Pages at
  `www.khalilmanns.com`.
- Content collections: `posts` (long-form, with categories and tags),
  `microposts` (short, tagged, separate page titled "Anti-Social Media"),
  `spec/about.md`.
- Features: Pagefind search, RSS, archive by category and tag, table of
  contents, light/dark/system theme switch, visitor hue picker.
- The Micros page uses a different layout from every other page (dark, no
  banner, its own nav order: Home · Archive · Micros · About · Github).
